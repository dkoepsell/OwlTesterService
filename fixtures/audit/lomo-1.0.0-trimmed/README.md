# LOMO 1.0.0, trimmed (golden audit fixture)

Source: the Legal Obligation Metadata Ontology (LOMO) release `lomo-v1.0.0.zip`,
version 1.0.0 (2026-07-10), by the Publications Office of the European Union,
licensed under CC BY 4.0 (see `LICENSE`; the release's `NOTICE` is kept as shipped).

This is a subset of the release, unchanged file by file: the ontology, the four
controlled vocabularies, both shapes files, one IOPA code list, the CI
configuration and the script it runs, `CHANGELOG`, `pyproject.toml`, two example
files, three LFDS files, the two legacy files that are inconsistent with the
ontology and one more legacy file (the only small one that uses the
`result-category#` form). It is used only as test data for the full artifact audit
(`SPEC-audit.md`); `fixtures/audit/expected-lomo.json` lists what the audit must
find in it.
