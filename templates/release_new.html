Build an audited release

Start from one OWL file (from Protégé, bfo-agent or Kindwork). The builder asks for what the file does not already say, builds the release with ROBOT, writes its documentation, audits it, and packages it with a verification record. You also get a git repository to continue in, so the next release can be made in CI. Nothing is published unless you choose to, with your own GitHub token.
